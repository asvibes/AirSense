Method and interpretation

  • The generator creates 168 hourly timestamps from 1–7 January 2026 for each of three fictional rooms and records CO2, temperature, and relative humidity at each timestamp.
  • Values are deterministic formulas with room and time-of-day variation; the CSV labels every row with source dataset and dataset label synthetic_demonstration.
  • Means are arithmetic means; min/max are observed generated values; exceedance counts compare CO2 samples strictly greater than the illustrative cutoff. No inferential or predictive analysis is performed.
  • There are 60 of 504 CO2 samples (11.9%) above that illustrative cutoff. This describes this generated dataset only.
  • Reproduce the CSV and this HTML report from the repository root with python tools/generate_analytics_report.py. Run with --check to verify the checked-in outputs match the generator.
