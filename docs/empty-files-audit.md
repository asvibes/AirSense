## Interpretation

An empty file indicates only that its tracked file size is zero. It does not by itself establish whether a feature is planned, optional, obsolete, or implemented elsewhere. Check the current [implementation status](./PRD.md) and active application code before treating any listed path as missing functionality. In particular, legacy empty templates and DALTON/vendor adapter placeholders are not the current dashboard implementation.

## Refreshing this inventory

Run this PowerShell command from the repository root to list tracked zero-byte files:

```powershell
git ls-files | ForEach-Object {
    if ((Test-Path -LiteralPath $_ -PathType Leaf) -and
        (Get-Item -LiteralPath $_).Length -eq 0) {
        $_
    }
}
```

Update the count and path lists above from the command output after adding/removing files, filling a placeholder, or merging another branch. This report is a checked-in snapshot, not an automatically generated inventory.
